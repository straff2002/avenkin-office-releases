# Avenkin Office releases

Signed builds of [Avenkin Office](https://avenkin.com/office/), the desktop app for organisations
whose technicians use Avenkin in the field. Each release carries the installer, the user guide and
a `SHA256SUMS` file. The download page at <https://avenkin.com/office/download/> repeats the
checksums and explains how to verify a download.

This repository holds releases only. The source is kept privately by Skunkworks NZ Ltd.
